# Scientific Calculator

A professional scientific calculator built with HTML, CSS, and JavaScript.

## Features

- Basic operations: `+`, `−`, `×`, `÷`, `%`
- Scientific functions: sin, cos, tan and their inverses, ln, log, √
- Powers and roots: x², xʸ, x!, 1/x
- Constants: π, e
- DEG / RAD angle mode toggle
- Calculation history (click a history entry to reuse its result)
- Keyboard support (digits, operators, Enter for `=`, Backspace, Escape to clear)
- Safe expression parser — no `eval()`

## How to use

Open `index.html` in any browser — no setup needed. Or use the GitHub Pages link.
